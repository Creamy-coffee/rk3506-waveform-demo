# AB5 联调差距盘点与待办（2026-10-20 19:50 实测）

> 主机侧（RK3506）实测后整理。所有结论都有抓包证据，附文件可复核。
> 结论：**接口层目前只跑通了「波形帧 + 锁相帧」两帧，第三帧（频谱）和 2 Mbaud 都还没生效。**

---

## 一、实测抓到的东西

| 项 | 实测值 |
|---|---|
| 串口波特率 | **921600**（按 2 Mbaud 抓是乱码，按 921600 正常解析） |
| 波形帧 | `V32CAP3!` fid=1396..1399，**pts=1024**，**dec=1**，CRC 全 OK |
| 锁相帧 | `V32MEAS!` wid 与波形帧一一对应（关联正确），CRC 全 OK |
| **帧间距** | **4268 字节** = 4140（波形）+ 128（锁相） |
| 频谱帧 | **一帧都没有** |

复核办法（附件里就有一段当时的抓包）：

```bash
python check_v32_frame.py 实测抓包_20261020_1950.bin
```

现在的输出是「波形 5 帧，锁相 5 帧，**频谱 0 帧**」。

## 二、还没达到期望的 4 件事

### ① 频谱帧 `V32SPEC!` 没有发出来  ⚠️ 最关键

| | |
|---|---|
| **现象** | 帧间距 4268，只有两帧；一个 `V32SPEC!` 都没收到 |
| **期望** | 一组三帧：**波形 4140 + 锁相 128 + 频谱 4144 = 8412 字节** |
| **说明** | 格式见《频谱帧与窗函数命令》文档第四节；示例帧 `sample_3_spec.bin` 可按字节对照 |
| **验收** | 抓包里 `V32SPEC!` 出现次数 = 波形帧次数；`check_v32_frame.py` 能打印第三行 |

> 怀疑：串口器里没有加第三个发送分支，或者加了但没使能。
> 最快的自查：确认发送状态机里存在 `V32SPEC!` 的魔数输出。

### ② 串口波特率还是 921600

| | |
|---|---|
| **现象** | 按 2 Mbaud 收是乱码，按 921600 收完全正常 |
| **期望** | **2 Mbaud（2,000,000 bps，8N1）** |
| **为什么必须** | 三帧一组 8412 B：921600 下只有 **11 组/秒**（波形都卡）；2 Mbaud 下 **23.8 组/秒** |
| **主机侧已确认可行** | 板上回环自测：**2 Mbaud 512 字节逐位一致，实测 140.1 kB/s**；1.5 Mbaud 也通过；3 Mbaud 失败（分频误差） |

> 注意：主机**不能**用 `busybox stty` 验证 2 Mbaud（报 `Inappropriate ioctl`），
> 需要直接写 termios 或用主机程序自带的回环自检。所以"stty 看不出来"不代表不支持。

### ③ 抽取倍数 `decimation` 恒为 1

| | |
|---|---|
| **现象** | 帧头 `decimation = 1`，一帧 1024 点 @65 MSPS = **15.8 µs** |
| **后果** | **低于约 63 kHz 的信号看不到完整周期**（500 Hz 一个周期 2000 µs，一帧只占 0.8%） |
| **期望** | 支持 `decimation = 1..256`（2 的幂），帧头如实填写 |
| **主机侧已就绪** | 已实现"按 FFT 频率自动选抽取倍数"并发送命令 `0xA5, k`；也接受任意 dec 的帧（采样率自动 = 65MHz/dec）。**只等 FPGA 接收命令 + 真正丢点** |

> 抽取前请做**抗混叠**（boxcar 平均或 CIC），否则高频会折叠成假峰。

### ④ 锁相完全没测到信号

| | |
|---|---|
| **现象** | `status = 0x16`（只有 present / ratio_valid / same_source）、`qual = 0`、**`amp1 = 0.0 counts`** |
| **后果** | 主机按规则屏蔽幅相显示：频率退回本地 FFT、相位差显示「—」 |
| **判断** | **不是接口问题**，是模拟输入侧没进来有效信号 |
| **建议排查** | ① 信号源是否真的接到输入端（幅度/频率） ② 是否接到了另一个通道 ③ ADC 是否超量程/欠量程 |

## 五、建议的处理顺序

1. **先补频谱帧 + 2 Mbaud**（这两件决定方案能不能落地）
2. 再做**抽取**（低频可视范围）
3. 锁相那条单独查**模拟输入**（跟前两项无关，可并行）
