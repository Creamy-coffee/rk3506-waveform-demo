# 128x256 images — 2026-10-29

Image protocol remains V32IMG1 v1, with the existing 16-bit width/height fields, 32-byte payloads and image/packet CRC32. Receiver capacity is now 4096 bytes and 128 chunks. The previous single uint64_t chunk bitmap is replaced by two words, with masked shifts and word selection, so chunk indices 64..127 are independent and safe. Dimensions are bounded to 256 per axis and total storage to 4096 bytes; 256x256 is rejected. Legacy sizes remain supported.

Windows sender defaults to width 128, height 256; landscape 256x128 is also supported. Square and 2:1 legacy presets remain. Crop geometry, previews, dithering, PBM headers, byte/packet/time estimates and request metadata use the selected dimensions. 4096 bytes / 128 packets take 786.432 seconds of playback per round at the current fixed 1000 Bd / three repeats, excluding uploads. Four upload slots are reused.

The screen canvas uses aspect-preserving nearest-neighbor scaling, including noninteger scale ratios: portrait 128x256 renders at 192x384, landscape 256x128 at 704x352. It does not fabricate extra image detail. Image transfer needs no FPGA bit change.

Validation includes real packet encoding and size checks; sanitizer-backed receiver tests for both orientations, reversed packet order, duplicates across the 64/65 boundary, all pixels and CRC rejection; sender mock full 128-packet transfer; eight dithering modes and running HTTP/JS/token checks. Production UI regressions receive full 128-packet valid images in both orientations and verify dimensions in the labels. Native previews are synthetic, not physical RF image reception. The ARM binary has been deployed; a complete 128x256 RF transfer has not been run in this change.

Separate source-referenced frequency response sweep: 250 kHz..5 MHz, CH1, 13 settled HRM frames per point; relative change -0.0175..+0.0425 dB against 1 MHz. This combines generator, cable and receiver response, so no receiver-only calibration table was applied. Precision THD calibration and uncertainty remain pending an independent known reference.
