# 数学运算、拖动与屏端触发修复（2026-10-28）

已在 RK3506 实屏验证。FPGA 由用户烧写，本端仅通过 JTAG 回读，
`REGISTER.USR_ACCESS=16556a03`，本次未改写 FPGA bit。

## 数学运算

直接故障是绘图控件只渲染 trace0/1，却把数学结果写到 trace2，因此除了
直接复用 trace0/1 的 XY，其余运算虽有计算都不可见。此外，数学缓存原为
1024 点，但循环使用完整 RAW 帧长，收到4096点时存在越界风险。

现在渲染第三条绿色 M 迹线，缓存按 `WAVE_MAX_FRAME` 分配。每次显示从缓存
的同一对原始样点重新计算，因此暂停后切换运算也立即生效。上方标注运算、
独立显示范围与量纲：加/减为 V，乘为 V²，除为无量纲 ratio。分母绝对值
小于2个ADC码时标记无效并断线，不用0伪造有效结果；全部不可除时显示
`DIV ZERO / LOW DEN`。独立量程不代表与左侧 CH1 电压轴共用标定。

菜单次序为 OFF → A+B → A-B → A×B → A÷B → XY → OFF，默认关闭。
数学运算需要同一帧、同一时刻的两路原始样点。开启数学时若正在跨帧长窗，
先切回合法帧内窗口；之后手动进入长窗则显示 `RAW FRAME ONLY`，不把分别
压缩的两路 min/max 极值错误地当作同时采样做运算。

## 拖动

频谱图注册按下和持续按压事件，用实际绘图区坐标更新光标，不再仅响应点击。
示波器关闭光标时，拖动绘图区上下移动当前“移 CH1 / 移 CH2”选中的通道；
“归零”恢复两路位置。位移只影响显示，不修改 ADC 样点和 Vpp/RMS 等测量。
左侧电压轴及电压光标按 CH1 的显示位置换算。数学迹线保持独立量程；XY
不应用这项时域位置移动。

开启光标后，按下时选定最近的一条 T/V 光标，整次拖动保持同一条，越过另一
光标也不会跳换。读取触摸驱动保存的实际落点，保留此前逐 SYN_REPORT 处理
和释放位置不归零的修复。

## 触发与单次的实际能力

触发源为 CH1，电平保持绝对 ADC 码值，界面换算为电压。边沿检测带
`max(1码, 帧内幅度范围的1%)` 的重新武装滞回；选择具有完整前/后样点的
过零点，约20%为预触发位置，不再取帧首边沿后强行夹到窗口边界。

- AUTO：命中时对齐，否则自由刷新。
- NORMAL：未命中时保留上一帧，并显示 TRIG WAIT。
- 单次：忽略点击前的帧，等待之后接收的帧满足边沿条件，接受该帧后冻结，
  显示 SINGLE HOLD / 已触发；RUN 或 AUTO 可以退出，复位清除状态。

**这是屏端接收帧内触发，不是 FPGA 硬件单次采集。** UART 接收线程继续
运行。无法保证捕获 FPGA 没有传输的帧间瞬态；真正的硬件单次/连续预触发
缓存需要另一项 FPGA 协议与采集链工作，不能用这个按钮冒充已完成。
操作说明已包含上述边界。

## 验证

Native ASan/UBSan 回归在生产 UI/plot/parser 上验证四种运算的实际样点、
数学第三迹线的绿色像素、暂停后重算、除零断线、帧内窗口限制、完整预/后触发、
无边沿等待、单次命中后保持缓存、恢复运行与 AUTO、选定通道位移、光标锁定
和频谱连续滑动，并保留原有调制、图片、FFT、相位资格与协议测试。

实机使用发生器 CH2 的1 MHz正弦、0.3333333 Vpp，另一输入保持原设置。
实际 evdev 手势完成四种数学菜单、两路分别位移、归零、AUTO触发、单次、
恢复运行、频谱拖动；通过运行中 SIGUSR2 导出控件真实位置定位按钮，不开
第二个串口读者。该信号仅在有界测试窗口使用，发生器原设置已回读恢复。

- 原始抓包5,323,680字节，记录器 accepted=written，overflow/error均为0。
- RAW：1106帧 CRC 正确，坏候选0，帧序缺口0。
- 单次后两张独立截图，波形区域变化像素为0，串口仍持续收帧。
- CH1向上拖动后，蓝色迹线中位位置上移51像素；归零恢复位置。
- 新bit真实HRM帧105帧 CRC 正确，坏候选0。v2线上THD字段为0，Linux按功率
  计算并检查资格；当前H2～H5低于噪声，正式THD显示 `< NOISE`，而不是0%。
  这是短时功能/共存检查，仍没有完成物理THD精度与前端校准。

实屏与抓包保存在主工程 `firmware/reports/scope_controls_20261028/physical/`；
JTAG 回读在同级 `identity_console.log`。界面显示刷新与 RAW 到帧率不同，
第三条迹线增加绘制负担；数学开启时实屏观察约12～15 UI FPS，不将以前
双迹线的帧率数字套到当前三迹线配置。

## 部署与回退

最终安装SHA256见主工程 `firmware/reports/scope_controls_20261028/deployed.json`。
板上备份 `/usr/bin/waveform_demo.pre_controls_20261028`。安装后保持示波器页、
A+B绿线和AUTO触发可见，位置归零、光标关闭，串口保持唯一读者。谐波试验后
已明确发送关闭命令；GUI 默认关闭，不把 GUI 的本地默认值当成硬件 ACK。

`SIGUSR1`保存真实 framebuffer，新增`SIGUSR2`仅在UI线程导出布局用于诊断；
信号处理器本身只置标志，不直接操作 LVGL。
