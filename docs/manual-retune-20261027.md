# 调制分析页的显式对频

真实数据源的调制页将原“自动”按钮改为“对频”；示波器等其他页面保持原自动框窗行为。未开启分析时，对频按钮禁用。

发生器改变载波频率后，点击对频：

1. 获取最近1.5秒内、当前所选通道的有效FFT频率测量。
2. 把该测量快照转换为DDC FCW，保留制式、通道、抽取档位。
3. 复用250ms连点合并和现有直接Apply流程，不先发送关闭分析。
4. 用ANA回显的mode/channel/R/FCW确认应用；写入失败不冒称生效。

没有新鲜有效频率时显示“频率无效”，不发命令，不退回10MHz、不借用另一路频率。同一FCW重复点击不发送命令，也不清空已有bit计数。用户在延后发送前切换制式/通道/档位会取消该对频快照，避免把旧通道测量误用到新配置。

这是手动对频，不是持续自动跟踪。FFT峰值也不保证是 suppressed-carrier PSK的精确载波中心或多音信号的基波。需要精确已知中心时仍可使用现有串口命令直接配置，并核对ANA回显；不能把峰值误差当作绝对频率校准。

实机发现固定2MHz BPSK的两次FFT峰值相差24Hz，导致不同FCW重配。现在增加限定的保持策略：只有BPSK已锁定、PN7至少256次训练后检查零错、累计擦除为0、最新完整ANA与当前目标/通道/抽取及解码器配置均匹配时，峰值变化不超过符号率的1/16则保留原DDC和计数，并记录`keep verified BPSK`及实际目标、测量值、差值和容限。1000Bd时容限62.5Hz。频率读数、DDC实际回显和原始样点不改；这是已有参考接收成功时避免抖动重启，不是降低FFT或采样精度。其他制式、未验证状态、参考有错/擦除、失锁或明显换频仍直接对频；直接串口频率命令保持精确、不受此保持策略影响。

主机回归覆盖：真实CRC测量帧解析、正确通道选择、显式FCW发送、模式/通道/档位保留、重复点击幂等、测量过期、所选通道无效时禁止借用另一路、不同用户配置取消快照、未开分析时禁用、其他页面自动按钮语义不变、八档字形与完整LVGL页面回归。

实机验收：固定制式与已知符号率，将发生器从1MHz切到2MHz；先确认DDC保留原值，再点击对频，观察请求日志及ANA的FCW更新、重新捕获参考序列；再次点击相同目标时计数不清零、不重新进入预热。源与屏幕收尾恢复AM。当前文档描述实现和主机验证，实机结果另行记录。
